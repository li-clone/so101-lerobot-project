# ACT v2 结果

## 数据与训练

| 项目 | 值 |
|---|---|
| 数据集 | `so101_pick_place_v2_70` |
| 构成 | v1 50条 + 定向补数20条 |
| episodes / frames | 70 / 23,868 |
| steps / batch size | 50,000 / 16 |
| 最佳保存点 | 30,000 |
| 最佳 eval loss | 0.2643 |
| 保留模型 | 30k、50k |
| 部署参数 | `n_action_steps=50`，`max_relative_target=None` |

完整验证曲线见 [`act_v2_eval.csv`](../results/training_curves/act_v2_eval.csv)。

## 平衡实机评测

| 距离 | 成功 | 成功率 |
|---|---:|---:|
| 近 | 4/5 | 80% |
| 中 | 5/5 | 100% |
| 远 | 4/5 | 80% |
| 总计 | 13/15 | 86.7% |

观察到的失败模式：

- 近距离偏抓线束边缘；一次抓取后在前往放置区时推动黑色目标盒，最终放置失败。
- 极远位置能够观察到空抓并反复尝试，但仍未成功夹取。

逐次记录见 [`act_v2_trials.csv`](../results/evaluation_csv/act_v2_trials.csv)。远距离失败的精确 episode 顺序未在实验当日文字记录中保留，因此 CSV 不伪造该编号，而以组级汇总行保留 4/5 事实。

## 比较限制

v1 与 v2 的验证划分、物体距离分布和实机评测协议不同。`0.2643 < 0.3095` 和 `86.7% > 80%` 是各阶段事实，不构成严格受控的模型优越性结论。后续模型对比应复用完全相同的数据、初始位置和 trial 清单。
